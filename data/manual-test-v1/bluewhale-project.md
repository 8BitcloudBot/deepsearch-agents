## 技术选型理由

- 向量检索选 Qdrant local 模式：单机部署、零外部依赖，语料规模（千级分块）下足够；
- 嵌入选 paraphrase-multilingual-MiniLM-L12-v2（384 维）：中文表现稳定、CPU 可跑；
- 编排选 LangGraph 固定 DAG：流程可预测、易测试，放弃自由 Agent 循环；
- 实时网络检索选 Tavily：中文命中率可接受，逐轮开关保证 fail-closed。
