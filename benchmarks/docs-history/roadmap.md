# Deepsearch Research Assistant Roadmap

## 项目目标

构建一个面向 AI 应用开发与大模型研究新手的多轮对话研究助手。用户可以结合小型本地知识库、当前会话文件和实时 Web 信息连续追问，获得简洁、可回链、可下载的研究结果。

## 交付原则

1. **对话闭环优先。** 每轮产生可读回答、声明到证据映射和可继续追问的上下文。
2. **证据精简。** 每轮只保留支持结论的代表性片段，不传递完整网页、文件或低价值元数据。
3. **确定性编排。** LangGraph 管理固定步骤，DeepAgents 只负责一次有界规划。
4. **隔离与可追溯。** 用户、会话、附件和报告隔离；事实性结论必须回链证据。
5. **按风险验证。** 最近责任边界证明行为，package 收尾运行完整离线门禁。
6. **真实能力不外推。** 未经授权和实测的 Provider 质量、成本、延迟或成功率不写入结论。

## Current Product Boundary

当前 package 固定包含：

- SQLite 本地认证、会话、回合、附件元数据和报告索引；
- 本地知识库始终启用，Web 每轮可选，会话文件存在时自动参与；
- Qdrant Local dense + sparse 混合检索与 RRF；
- LangGraph 固定回合流和一次有界补充检索；
- 声明、证据、限制和精简 WebSocket 事件；
- React 对话界面、引用详情和单份累计 Markdown 报告；
- 简化的 admin 数据查看与清理能力。

当前 package 明确不包含：

- MySQL、结构化数据或数据库测试种子；
- 一次性任务工作台、自由工具循环或递归委派；
- PDF/JSON 用户下载、旧合同兼容或旧工件迁移；
- 注册、复杂用户管理、分享、恢复归档或知识库管理页面；
- 未经授权的真实 Provider 验收、发布或部署。

## Next Boundary

后续产品能力从真实对话质量、知识库命中质量和来源排序问题出发，以小包方式继续优化。任何新的真实 Provider 验收仍需单独明确授权，并且只记录状态、计数和工件名；不恢复已删除的数据库来源和旧任务合同。
