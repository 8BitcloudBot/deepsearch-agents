# Phase 6 — Observability

**Status:** Not started
**Entry Gate:** Phase 3 event semantics and Phase 5 strategy identifiers

## Goal

建立从最终声明到 Agent、工具、来源、Token、费用和延迟的可追踪链路。

## Deliverables

- 版本化事件契约；
- 结构化日志与 trace/span；
- 质量、延迟、成本和失败指标；
- 前端运行详情视图。

## Minimum Acceptance

一个研究任务可从报告声明反向定位到调用链和来源，指标能够由测试或固定运行复现。

## Non-goals

本阶段不承担任务持久化、服务重启恢复或审批状态机。
