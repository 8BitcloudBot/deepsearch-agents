# Phase 1 — DeepAgents Capability Examples

**Status:** Accepted
**Release:** `v0.0-deepagents-examples`

## Goal

用独立、可运行的最小示例掌握 DeepAgents/LangGraph 的关键能力，为产品代码建立经
实际版本验证的 API 基线。

## Delivered

- invoke、stream 与 chunk 示例；
- 子 Agent 与 Runnable 兼容示例；
- interrupt/resume、backend/store/memory 示例；
- middleware 与 Skills 示例；
- 离线测试、可选真实模型 smoke 和学习说明。

## Non-goals

示例不是最终产品架构，不复制为 Phase 2-9 的第二套业务实现。

## Acceptance

每个能力有独立入口、行为测试和版本/API 证据。该阶段已经验收，不再作为当前开发
范围。
