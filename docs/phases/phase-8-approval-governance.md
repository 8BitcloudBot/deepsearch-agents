# Phase 8 — Human Approval and Cost Governance

**Status:** Not started
**Entry Gate:** Phase 7 persistent task state

## Goal

为计划、风险工具和报告发布加入可恢复的人工审批，并用硬预算约束 Token、费用、时间、
工具调用和并发。

## Deliverables

- 审批状态机和前端操作；
- 风险工具与发布审批；
- Token、费用、时间、工具和并发预算；
- 超限降级与恢复后的审批一致性测试。

## Minimum Acceptance

审批可以暂停并跨重启恢复；任务不会在超过硬预算后静默继续。

## Non-goals

不扩展新的研究领域或为作品集展示增加无验证指标。
